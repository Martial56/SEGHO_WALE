Lecteur d'empreinte digitale
Configuration du périphérique biométrique du kiosque de pointage
Le lecteur d'empreinte est un périphérique branché directement sur le poste du kiosque. Une fois installé, son logiciel (SDK) fait tourner un petit service local sur cette machine (adresse 127.0.0.1) — le navigateur du kiosque s'y connecte directement pour lire une empreinte, sans jamais passer par le serveur SEGHO-WALE. Tant qu'aucune URL n'est renseignée ci-dessous, le kiosque affiche un message indiquant que le lecteur n'est pas configuré.
