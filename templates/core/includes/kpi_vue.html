Le relevé coûte près de trois secondes ; le recalculer à chaque clic pendant qu'on cherche sa semaine n'avait pas de sens. Les listes se répondent entre elles sans passer par le serveur : changer d'année refait les mois, changer de mois refait les semaines. Le mois n'est pas qu'une période, c'est aussi le cadre dans lequel on choisit une semaine — d'où `cadre_mois`, qui vaut aussi quand la période retenue est la semaine, là où `mois` ne dit que le premier cas. {% endcomment %}
