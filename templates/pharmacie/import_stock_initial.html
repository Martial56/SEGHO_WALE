Importer le stock initial

Pour démarrer une pharmacie avec les produits et les quantités déjà en sa possession, plutôt que de les créer un par un puis de saisir le stock à la main. Un produit déjà connu du catalogue voit juste son stock alimenté ; un produit inconnu est créé automatiquement (avec son code d'origine s'il est libre) puis reçoit son stock initial. Chaque ligne importée est enregistrée comme un mouvement « Stock initial » et s'ajoute au stock déjà présent (elle ne l'écrase jamais).

Fichier CSV, Excel (.xlsx) ou JSON avec les colonnes code, nom_produit, type, quantite et unite — indiquez au moins un code ou un nom par ligne. Le produit est d'abord retrouvé par son code ; si votre fichier utilise une autre nomenclature (ancien registre, liste externe...), il est retrouvé par son nom exact à la place. S'il n'existe encore nulle part, il est créé avec le nom, le type et l'unité indiqués (n° de lot reste pour l'instant un simple repère, non lu à l'import). Télécharger le modèle Excel , pré-rempli avec les mêmes colonnes que le tableau du stock — pratique pour les produits déjà au catalogue ; ajoutez simplement une ligne pour chaque produit qui n'y figure pas encore.
